# 🚦 Drift Start Tree HUD (Синхронизированный светофор для Assetto Corsa)

Разработано для соревнований сообщества **ГАЗДЕРЖИМ.РФ** ([twitch.tv/sergeyprimo](https://twitch.tv/sergeyprimo)).

## ⚡ Особенности
- **0 мс задержки (нулевой рассинхрон):** Использует серверные метки времени (`ac.getSim().time`) и Custom Shaders Patch (CSP) Shared Events. Зеленый свет загорается абсолютно синхронно у всех пилотов независимо от пинга.
- **Автоматическая загрузка:** Не требует ручной установки пилотами. Подключается напрямую через сервер/расширение трассы (`extension/drift_start_hud.lua`) или как отдельное приложение AC.
- **Управление отображением для пилотов:**
  - Кнопка **`─ Свернуть / ⤢ Развернуть`** — сворачивает светофор в ультра-компактную мини-панель (56px).
  - Кнопка **`⏻ Отключить`** — скрывает светофор с экрана, оставляя аккуратную кнопку-пилюлю `[ 🚦 Включить светофор ]` по центру вверху экрана для восстановления в 1 клик.
  - Команда в чате **`!hud`** / **`!светофор`** — быстрое переключение видимости.
  - Не блокирует управление автомобилем и меню ESC (`ui.WindowFlags.NoNav`).
- **Судейская панель (Сергей Primo и назначенные судьи):**
  - Кнопка **`▶ СТАРТ`** и запуск по настраиваемой горячей клавише (F8, F7, F6, F5, Пробел и др.).
  - Кнопка **`✖ СБРОС`** при фальстарте.
  - Настройка задержки ламп: пресеты 0.5с (PRO), 0.75с (RDS), 1.0с (STD), 1.5с + плавный слайдер.
  - **`🔴 ОТКЛЮЧИТЬ СВЕТОФОР НА СЕРВЕРЕ`** — глобальное отключение светофора судьёй во время перерывов/тренировок с мгновенным оповещением всех пилотов (`⚠️ СВЕТОФОР ОТКЛЮЧЕН СУДЬЁЙ НА СЕРВЕРЕ`).
  - Система распределения судейских прав (Главный админ может назначать судей из пилотов прямо в игре).
  - Поддержка команд чата: `!start`, `!stop`, `!disable`, `!enable`, `!judge <ник>`, `!unjudge <ник>`.

## 📦 Установка на трассу
1. Скопируйте `drift_start_hud.lua` в `content/tracks/<имя_трассы>/extension/`.
2. В `content/tracks/<имя_трассы>/extension/ext_config.ini` добавьте:
```ini
[SCRIPT_START_HUD]
SCRIPT = drift_start_hud.lua
ACTIVE = 1
```
3. Для автоматической раздачи через Content Manager используйте архив `UW_STKPilot_start_hud.zip`.
